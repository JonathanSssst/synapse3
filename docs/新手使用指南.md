# 从下载到跑起来：完整操作指南

面向第一次使用的人。按顺序做，全程大约 40 分钟，其中一半时间在等第三方软件下载。

**你会得到什么**：一个跑在你自己电脑上的 QQ 机器人。它有固定人设和长期记忆，你私聊它，它像人一样回你——文字分条发、发表情包、发语音、戳一戳。

装上就是能聊天的完整形态。**B 站、抖音、QQ 空间、联网搜索、电脑助手这些不装就没有**——它们在「扩展」页里，需要的时候点一下就行。这样你不用为用不到的能力付 token 钱。

---

## 开始前：你需要自己装两个软件

本程序**不代装、不代登录**这两个，必须你自己来。它们都是免费的。

| 软件 | 干什么的 | 在哪拿 |
|---|---|---|
| **SnowLuma**（2.4.0 或更高） | 让机器人能登录 QQ。官方叫「OneBot v11 网关」 | 项目 Release 页 |
| **DeepSeek Harness**（简称 DSH） | 真正「思考」的那一层，负责理解你的话、决定怎么回 | 项目 Release 页 |

> Node 运行时**不用装**，安装包里已经带了（`runtime/node.exe`）。

两件事先确认好，后面全靠它们：

1. SnowLuma 解压后启动，浏览器打开 `http://127.0.0.1:5099` 是它的管理界面 —— **在这里扫码登录机器人的 QQ 号**。
2. DSH 装好后要**登录你的账号**，并且保持运行。它每次启动 API 端口都会变，不用管，向导会自动探测。

## 第 1 步：放好 exe

下载 `SynapseHub-0.1.0-x64.exe`，**放进一个单独的空文件夹**，比如：

```
D:\Synapse\SynapseHub-0.1.0-x64.exe
```

为什么要单独建文件夹：**exe 放在哪，你的配置和数据就存在哪**。程序会在它旁边生成 `config\`、`data\`、`backups\`。放在「下载」文件夹里，哪天清理下载就把机器人删了。

不要放 `C:\Program Files\`，那里普通权限写不了文件。

> 这个版本是「便携版」：每次双击会把自己解压到临时目录再启动，所以你**不需要安装**，也不会写注册表（除了你自己打开的开机自启）。想换电脑，整个文件夹拷走就行。

## 第 2 步：双击启动

双击后**会有一段什么都没发生的空白期，大约 30～90 秒**——它在解压 350 MB 自己的运行文件，不是卡死了。第一次启动最慢。

然后弹出控制台窗口，标题是「Synapse 3 控制台」。左边有四个页签：**服务 / 审批 / 配置 / 日志**。

第一次启动会**直接停在「配置」页**，因为还没有任何配置。这是正常的。

## 第 3 步：让 SnowLuma 登录 QQ

1. 启动 SnowLuma（它自己的启动方式，通常是目录里的 `启动.bat` 或 exe）。
2. 浏览器打开 `http://127.0.0.1:5099`。
3. 用**你要当机器人的那个 QQ 号**扫码登录。
4. 确认它的 HTTP 端口是 3000、WebSocket 端口是 3001（默认就是，没改过不用动）。

⚠️ 这里登录的是**机器人**的号，不是你自己的号。机器人和你必须是两个不同的 QQ。

## 第 4 步：启动 DSH 并登录

启动 DeepSeek Harness，完成登录，让它保持运行。不用管它的端口号。

## 第 5 步：填配置（三个步骤）

回到控制台的「配置」页，从上往下填：

### 第 1 步 · 你是谁

| 填什么 | 说明 |
|---|---|
| **你的 QQ 号** | 填**你自己**的号。这是最容易填错的一项——很多人在这里填了机器人的号，结果机器人不认主人，审批功能全废 |
| 允许私聊的 QQ 号 | 留空就行，程序会自动把你的号加进去 |
| 允许的群号 | 想让它在群里说话就填群号；留空则只在私聊里工作 |

### 第 2 步 · QQ 网关

| 填什么 | 说明 |
|---|---|
| SnowLuma 安装目录 | 点「选择」挑到解压出来的那一层文件夹。填了它才知道怎么帮你重启 |
| HTTP 地址 | `http://127.0.0.1:3000`，默认值，不用改 |
| WebSocket 地址 | `ws://127.0.0.1:3001`，默认值，不用改 |
| 访问令牌 | 在 SnowLuma 管理界面里能看到。空着通常也能连，填上更稳 |

### 第 3 步 · 智能体

| 填什么 | 说明 |
|---|---|
| API 地址 | **点右边的「自动探测」**，它会自己找到正在跑的 DSH |
| 访问令牌 | DSH 开了鉴权才需要填，没开就留空 |

点「自动探测」如果提示「没找到在跑的 DSH」，说明 DSH 没启动或没登录，回去做第 4 步。

### 保存

点最下方的**保存配置**。会看到提示「已保存，桥接已重启」。配置文件写好了，桥接会用新配置重新连 QQ。

## 第 6 步：验证它能用

1. 切到「**服务**」页，应该看到四行：

   | 服务 | 期望状态 |
   |---|---|
   | QQ 桥接 | 运行中（端口 3100） |
   | 数据面板 | 运行中（端口 3120） |
   | DSH 运行时 | 运行中（外部程序，只探测） |
   | SnowLuma 网关 | 运行中（外部程序，只探测） |

   如果桥接显示「未运行」，点它右边的「启动」，等 5 秒。

2. 用**你自己的 QQ** 给机器人发一句「在吗」。

   正常反应是：先回一条「🤔 收到，正在思考…」，几秒后再回正经内容。

   收到第一条但迟迟没有第二条 → 看「日志」页，通常是 DSH 没连上或者账号余额问题。

3. 回到「配置」页，把最下面「环境体检」展开，应该全是绿的。

## 日常怎么用

### 关窗口不等于退出

点窗口右上角的 ✕，**程序不会退出**，它缩到右下角托盘里继续跑，机器人照常回消息。

要真正退出：右键托盘图标 → **退出并停止服务**。

托盘菜单：

| 项 | 作用 |
|---|---|
| 显示控制台 | 把窗口叫回来 |
| 打开数据面板 | 用浏览器打开数据看板（3120） |
| 退出并停止服务 | 真退出，连机器人一起停 |

### 开机自启

侧栏底部有「**开机自启（后台）**」开关。打开后，下次开机不用再双击 exe —— 它会自己在后台起来，只挂托盘，同时把桥接和面板一起拉起。

### 审批：它想动你电脑的时候

机器人要读文件、改文件、执行命令之前，会发起一条审批。三个地方能看到，**在哪处理效果都一样**：

- 控制台「审批」页，点「通过」或「拒绝」
- 机器人会在 QQ 里问你，直接回「通过」或「拒绝」
- 侧栏「审批」旁边会有数字角标，有挂起项时会亮

不处理会超时，超时按拒绝算。

### 数据面板

「打开数据面板」会开一个网页（`http://127.0.0.1:3120`），能看聊天记录、记忆、日记、花费统计这些。只读，不会改任何东西。

### 日志

「日志」页按服务分栏，出问题时第一个该看的地方。桥接报错、发送失败、余额告警都在这里。

## 它能做什么

### 装好就有的（核心）

**聊天**
- 文字回复，可以主动**分多条**发（不是一大段，像真人那样一句一句说）
- 发**表情包**、**语音**
- **戳一戳**你、发图片、发文件、撤回消息
- 读你发的图片、理解转发消息
- 群聊里能分清谁在跟它说话

**记得住事**
- **长期记忆**：你说过的重要事情它会记下来，之后主动提起
- **人设**：默认「大肥鱼女友版」，纯文本放在 `config\persona\`，可以自己改措辞

**会自己找你**
- **主动唤醒**：到点会主动给你发消息，不是干等你说话
- **社交状态**：有心情、精力这类状态，会影响说话语气
- **自己的形象**：能改昵称、签名、头像

### 要装扩展才有的

在控制台左侧「**扩展**」页，点「装上」即可。装完**重启一次 DSH**，它才会知道多了这些本事。

| 扩展 | 能得到什么 |
|---|---|
| B 站 | 搜视频、看热门、看视频内容、记笔记、收藏、发评论 |
| 抖音 | 刷热门、看视频内容 |
| QQ 空间 | 看好友动态、发说说、点赞评论转发 |
| 联网搜索 | 上网查资料、看网页、搜图片 |
| 电脑助手 | 真的操作你的电脑：读文件、找文件、查状态、截图、看余额 |
| 睡眠计划 | 安排作息，睡着期间不主动发消息 |
| 读书 / 语料 / 参考图 / 吃喝 / 刷视频 / 生图 / 日记 | 对应的小能力 |

一个都不装也能正常聊天、记得住事、主动找你。

### 电脑助手要特别说明

这是它和普通聊天机器人最大的区别：能**真的操作你的电脑**。

每一次动手前都会走审批。你可以选择通过或拒绝；拒绝后它会换个方式，或者告诉你做不了。审批策略可以细化到「哪些操作永远允许、哪些永远不许、哪些每次都要问」。

**建议先装几天别的，熟悉了再开这个。**

## 装扩展

1. 控制台左侧点「**扩展**」
2. 找到想要的，点「**装上**」
3. 看到提示「已装上，桥接已重启；重启一次 DSH 才会生效」
4. **重启 DSH**（关掉再打开）
5. 回扩展页确认它左边有绿色竖条——那是「已装」

不想要了点「**卸下**」。卸掉之后它的工具会从模型的能力清单里彻底消失，不是隐藏，是真的不注册。

顶部「刷新市场」用来拉远端扩展索引。连不上也不影响内置的那些。

## 常见问题

**双击没反应，等很久都没窗口**
便携版第一次要解压 350 MB，慢的话两分钟。如果超过三分钟，看任务管理器里有没有 `SynapseHub` 进程：有进程没窗口，说明被别的实例挡住了（这个程序只能开一个）。

**提示端口 3100 已被占用**
已经有一个桥接在跑，可能是你之前手动启动的。控制台会标「正由外部进程占用（Hub 未托管）」。要么在任务管理器里结束那个 node 进程再让控制台启动，要么就用现有的那个。

**机器人不回消息**
按顺序查：
1. SnowLuma 里机器人 QQ 还在线吗（掉线要重新扫码）
2. 「服务」页桥接是不是运行中
3. 「日志」页有没有报错

**机器人只回「已收到：xxx」然后没下文**
这是账号余额不足时的保护行为。余额低于 5 元时，程序会**停止所有主动唤醒**，只回一条确认收到，避免欠费乱发消息。充值后自动恢复，不用改任何设置。

**改了配置没生效**
正常保存会自动重启桥接。如果桥接是外部启动的（提示「正由外部进程占用」），得手动重启那个进程。最省事的办法：托盘 → 退出并停止服务 → 重新双击 exe。

**换电脑怎么办**
把整个文件夹（含 exe、`config`、`data`）拷过去。前提是新电脑上 SnowLuma 和 DSH 也装好了并登录。

**想彻底删掉**
托盘退出 → 删除整个文件夹。程序不在系统里留别的东西（除非你开过开机自启，先把它关掉）。

**装了扩展但机器人还是不会**
按顺序查：
1. 扩展页里它左边有没有绿色竖条（没有就是没装上）
2. **重启过 DSH 吗**——新工具要它重新读一次配置才认得
3. 桥接重启成功了吗（提示里会写「桥接已重启」或失败原因）
4. 「日志」页有没有 `[extensions]` 开头的行，那里会写注册了几个工具、跳过几个

**扩展市场打不开 / 显示连不上**
远端索引在 GitHub 上，网络不通时拉不到。内置的 13 个扩展不受影响，照常能装。点「刷新市场」重试。

**这个版本不包含**

- **视频通话 / 桌宠**：还没做，扩展市场里也还没有。当前扩展能提供的只有「给机器人加工具」这一类。
- **自动安装 SnowLuma / DSH**：不代装。这两个有自己的登录态和许可证，代装反而容易出问题。
- **云端同步**：数据只在你本机。要备份就拷 `data\` 和 `config\`。
