# QQ 空间拟人助手（Synapse 3 v3.2）

- 定时发说说：随机 3~7 小时一条，只在 8:00~23:00；内容由流萤人设 + 最近活动/心情生成，第一人称碎碎念，不发工作总结；每条必配图（图库 `gallery/`，不够时自动生成）。
- 评论互动：每 2~4 分钟轮询自己的说说；发现新评论后按身份（主人/群友/陌生人）拟人回复，回复前随机等待 20~180 秒；恶意/广告评论直接无视。
- 风控保护：发说说或评论时如果返回“验证/扫码/风控/限制/登录”等信号，立刻暂停所有空间动作，并让桥接给主人发 QQ 求助；恢复方法：把 `state.json` 的 `paused` 改成 false。
- 状态/日志：`state.json`（运行状态）、`logs/qzone-events.log`（每条动作）。
- 测试：`node qzone-bot.mjs --once --dry` 只生成不发送；`--dry-comment` 测试回复生成；`--once --force-post` 立即发一条。
